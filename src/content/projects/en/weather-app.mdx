## Overview

Weather App is a learning project I built to learn React Native, inspired by the Weather app Apple
ships on the iPhone. It is a weather forecast app for
iOS and Android: you search for any city in the world and see the current temperature, the
conditions, wind, humidity, rain chance and the forecast for the coming days.

The data comes from <a href="https://www.weatherapi.com/" target="_blank" rel="noopener">WeatherAPI</a>. Searched cities are saved on the device, and the app tells you when
there is no internet connection.

## Technical decisions

### The background follows the weather and the time of day

The main screen changes its background image according to the conditions and whether it is day or
night in the selected city. WeatherAPI's condition codes are grouped into rain, clouds and clear
sky, and each group has a day and a night version.

> **What it cost:** the code grouping was written by hand. A condition that is not in any group
> falls back to the default background, so the list has to keep up with the codes the API returns.

### Search waits for you to stop typing

City search only queries the API half a second after the last keystroke. Without that wait, every
letter typed would become a request. Chosen cities go into a recent list stored on the device
itself, with up to six cities and no duplicates.

> **What it cost:** suggestions appear half a second after you stop typing. And recent cities stay
> on that one device, with no sync to another.

### No connection is a screen state

The app watches the connection the whole time. When it drops, the city screen shows its own notice
saying an internet connection is needed to search, instead of a generic error message.

> **What it cost:** the app does not keep the last forecast it fetched. Offline, it explains what
> happened but shows no weather for any city.

## Results and lessons

The same code runs on iOS and Android, with city search, recent cities saved on the device and the
no-connection handling working on both platforms.
